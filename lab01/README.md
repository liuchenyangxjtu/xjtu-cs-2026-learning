# Lab 1

这是 CS 61B Spring 2025 Lab 1 的 Arithmetic 练习。

## 本地打开

在 IntelliJ 中打开当前仓库里的 `lab01` 文件夹。项目 SDK 使用 Java 17 或更高版本，语言级别设置为 17，并把仓库外部的 `library-sp25` 文件夹添加为 Java Library。

## 文件

- `src/Arithmetic.java`：需要完成的代码。
- `tests/ArithmeticTest.java`：本地测试。

## 获取后续作业

在仓库根目录执行：

```bash
git pull skeleton main
```

然后在 IntelliJ 中重新打开新增的作业文件夹。
