# xjtu-cs-2026-learning

西安交通大学 2026 级计算机学习记录。

## 目录

- `lab01/`：CS 61B Spring 2025 Lab 1，包含 Java 源码、测试和作业说明。
- `c-basics/`：C 语言入门练习，包括变量、输入输出、分支、循环和基础计算。
- `c-arrays/`：数组遍历、逆序、求和、找最大值和访问顺序实验。
- `c-algorithms/`：冒泡排序、素数判断和约瑟夫环两种解法。

## CS 61B 作业流程

在仓库根目录获取后续课程作业：

```bash
git pull skeleton main
```

然后在 IntelliJ 中打开新增的作业目录，例如 `lab01`。项目 SDK 使用 Java 17 或更高版本，语言级别设置为 17，并在本机添加 `library-sp25`。

提交代码时：

```bash
git add lab01
git commit -m "lab01: update"
git push origin main
```

本仓库用于保存 GitHub 学习记录和代码版本。
